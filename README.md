# Description
This app is a simple AI app that creates a recipe based on ingredients added through a form.

Clicking on "Get Recipe" makes a backend call to an Express server, which pulls the recipe from OpenAI.

The result is then displayed in the UI.

# Build and Run

To build the project, first run `npm install` to install the packages.  

Then, in one terminal, ```npm run start:server```, and the server will start.  

In another terminal, run `npm run start:client` and the frontend will open up in a browser.
